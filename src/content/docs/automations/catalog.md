# Automations Catalog

The Automations Catalog is your dashboard for creating, managing, activating, and monitoring automated Instagram DM and comment response rules.

> **View in Application →** [Open Automations](/dashboard/automation)

![Screenshot placeholder: Automations Catalog](./images/automations-catalog.png)
> **Screenshot:** Automations Catalog showing active and disabled automation cards, trigger event tags, trigger keyword chips, execution counters, and status toggles.

## Overview

AnyDM Automations allow creators and brands to respond instantly to Instagram comments, direct messages, story mentions, and questions. When followers comment specific keywords (like "PRICE", "LINK", or "BUY") on your posts or reels, AnyDM automatically replies in the comments and delivers a customized direct message with purchase links.

## What You Can Do

- View all configured automation rules with real-time status (`Active`, `Disabled`, `Completed`).
- Create new automation workflows from scratch or pre-built templates.
- Toggle automations active or inactive with a single switch.
- Filter automations by status (`All`, `Active`, `Disabled`).
- Switch between Grid and List display modes.
- Track execution counts and follower growth metrics generated by each rule.
- Set scheduled start and end expiration dates for time-sensitive marketing campaigns.
- Open the visual flow builder to edit rule logic and message sequences.
- Delete obsolete automation rules.

## How to Use

### Step 1: Browse Existing Automations
1. Open **Automations** from the sidebar.
2. Review your active rules, their trigger events (Comment Keywords, Direct Message, Welcome Icebreaker, or Chat Menu), and execution counts.

### Step 2: Create a New Automation
1. Click **+ New Automation** in the top right.
2. Select whether to create a Comment-to-DM rule, Post Share reply, Story Mention flow, or Welcome profile flow.
3. This opens the **Visual Flow Builder** to configure trigger keywords and action responses.

### Step 3: Manage Rule Status
- Use the status toggle button on any automation card to quickly pause or activate the flow.
- Click the **Pencil / Edit** icon to modify nodes in the visual builder.
- Click the **Trash** icon to remove the automation.

## Supported Automation Trigger Types

| Trigger Type | Description |
|---|---|
| **Comment Automation** | Triggers when a user comments on any post or a specific post, with optional keyword filters. |
| **Direct Message Trigger** | Triggers when an inbound direct message containing specific keywords is received. |
| **Welcome Message Flow** | Triggers when a new customer opens chat and clicks a suggested icebreaker question. |
| **Persistent Menu Flow** | Triggers when a customer selects a persistent menu option inside the Instagram chat composer. |
| **Story Mention Flow** | Triggers when a user tags your Instagram account in their story. |
| **Post Share Flow** | Triggers when a user shares your post or reel into direct messages. |
