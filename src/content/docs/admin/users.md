# Admin User Management

Inspect registered creator accounts, adjust reward points, grant VIP Pro access, toggle staff privileges, and troubleshoot user issues.

> **View in Application →** [Open User Management](/dashboard/admin/users)

![Screenshot placeholder: Admin User Management Table](./images/admin-users.png)
> **Screenshot:** Admin User Management table showing user list, plan badges, point balances, connected Instagram accounts, superuser flags, and action menus.

## Overview

User Management gives administrators complete visibility over platform accounts. Staff can search for specific users, audit their subscription status and connected Instagram handles, manually credit or debit reward points, and grant VIP privileges.

## What You Can Do

- Search and filter all registered AnyDM users by name, email, or Instagram username.
- Inspect account plan details (`Free Trial`, `Creator Pro`, `VIP Pro`, `Expired`).
- View total points balance and referral statistics per user.
- Manually adjust a user's point balance or extend their subscription validity period.
- Toggle superuser or staff permissions for administrative staff.
- Deactivate or suspend problematic accounts.

## How to Use

### Step 1: Search for a User
1. Navigate to **Admin Panel > Users** (`/dashboard/admin/users`).
2. Type the user's email, name, or Instagram handle into the search box.

### Step 2: Edit Account Permissions & Points
1. Click the **Edit / Actions** button on the target user's row.
2. Modify user points, subscription tier, or staff status in the modal.
3. Click **Save User Changes**.

## Available User Attributes

| Attribute | Meaning |
|---|---|
| **User Identity** | Full name, email address, and avatar. |
| **Plan Tier** | Active subscription tier (`Trial`, `Pro`, `VIP Pro`). |
| **Points Balance** | Current unspent reward points. |
| **Connected IG Accounts** | Total Instagram professional handles linked by this user. |
| **Staff / Superuser** | Administrative permission flags. |
| **Joined Date** | Timestamp of initial platform registration. |
