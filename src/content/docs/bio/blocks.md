# Bio Blocks & Links

Bio Blocks are the core interactive elements displayed on your Link-in-Bio page, including custom web links, featured products, embedded media, and contact triggers.

> **View in Application →** [Open Link-in-Bio](/dashboard/bio)

## Overview

Blocks allow you to organize and present your content hierarchically. You can highlight your latest YouTube video, promote special discount links, showcase e-commerce product cards, or collect newsletter signups directly within your bio page.

## What You Can Do

- Add new link blocks, product cards, headers, and media items.
- Drag and drop or use move buttons to reorder blocks in real time.
- Toggle block visibility on or off without deleting the block.
- Edit block titles, subtitles, target URLs, and thumbnail media.
- Track individual click counts per block.
- Delete obsolete blocks.

## How to Use

### Step 1: Add a New Block
1. Navigate to the **Blocks** tab in the Link-in-Bio editor.
2. Click **+ Add Block**.
3. Select the block type (Link, Product, Header, Media).
4. Enter the **Title**, optional **Subtitle**, and the destination **URL**.
5. Upload an optional thumbnail icon or media file.
6. Click **Save Block**.

### Step 2: Reorder Your Blocks
- Hover over any block card and click the grab handle to drag it up or down.
- Alternatively, use the **Move Up** and **Move Down** arrow controls.
- Changes are instantly updated on the live preview simulator and public URL.

### Step 3: Manage Block Visibility
- Use the **Eye / Eye Off** toggle on any block card to temporarily hide or show it.

## Available Block Options

| Field / Action | Description |
|---|---|
| **Block Type** | Type of block: standard link card, product highlight, heading, or media container. |
| **Title** | Primary text displayed on the link card. |
| **Subtitle** | Secondary supportive text or promo code description. |
| **Destination URL** | External link or internal shop destination opened upon click. |
| **Media / Icon** | Thumbnail image or icon uploaded to accompany the link. |
| **Active Switch** | Toggle to show or hide the block from public visitors. |
| **Click Counter** | Total recorded visitor clicks on this specific block. |
| **Delete Action** | Permanently removes the block from your page. |
