# Smart Reel & URL Redirects

Smart Redirects allow creators to link Instagram Reels, post captions, and promotional short-codes directly to specific products, external links, or bio blocks through an intelligent URL resolver.

## Overview

When creators tell their followers *"Link in bio to buy!"* or share specific short URLs in captions and reels, visitors can paste or click the link into the Smart Input bar on your bio page. The Smart Redirect engine instantly resolves the link and forwards the user directly to the exact product or page.

## What You Can Do

- Enable or disable the interactive Smart Input bar on your public bio page.
- Create keyword or URL match rules (Exact Match or Contains Match).
- Route matches to multiple destination types: external URLs, specific product items, or bio blocks.
- Test routing rules in real time using the built-in test runner.
- Track total hits and traffic redirection count per rule.
- Customize the input placeholder, title, and button text displayed to visitors.

## How to Use

### Step 1: Enable Smart Redirects
1. Go to the **Redirects** tab in the Link-in-Bio editor.
2. Ensure the **Enable Smart Redirect Input** toggle is switched ON.
3. Customize the **Input Title** (e.g., *"Have a Reel or Promo Link?"*), **Placeholder**, and **Button Text** (e.g., *"Get Link"*).

### Step 2: Create a Redirect Rule
1. Click **+ Add Redirect Rule**.
2. Set a descriptive **Rule Title** (e.g., *"Summer Dress Reel #42"*).
3. Enter the **Input Match URL or Keyword** (e.g., `reel-summer-dress` or Instagram reel permalink).
4. Choose the **Match Type** (`Exact Match` or `Contains`).
5. Select the **Destination Type** (`External Link`, `Product`, or `Block`).
6. Enter or select the destination target and click **Save Rule**.

### Step 3: Test the Rule
1. Locate your rule in the list.
2. Click the **Test Rule** button.
3. Verify that the test runner confirms a successful match and shows the resolved destination.

## Available Rule Options

| Option / Field | Description |
|---|---|
| **Smart Redirect Switch** | Master toggle to show or hide the link resolver search box on your bio page. |
| **Input Title** | Heading above the input box guiding the visitor. |
| **Placeholder Text** | Placeholder prompt inside the search box. |
| **Rule Title** | Internal name for organizing your marketing campaigns. |
| **Match Keyword / URL** | Text or link pattern entered by the visitor. |
| **Match Type** | `Exact` (strict string comparison) or `Contains` (substring matching). |
| **Destination Value** | Target URL or product slug to forward the visitor to. |
| **Hits Counter** | Number of times visitors successfully triggered this redirect rule. |
