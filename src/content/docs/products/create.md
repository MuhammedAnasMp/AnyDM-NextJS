# Create & Edit Product

Configure product details, pricing models, downloadable digital files, media galleries, inventory, and automated delivery fulfillment for your items.

> **View in Application →** [Create New Product](/dashboard/products/catalog/create)

![Screenshot placeholder: Product Creation Form](./images/products-create.png)

## Overview

The Product Creation screen gives you all the tools required to publish sellable goods. When a customer purchases a product through AnyDM checkout, the system processes payment via Razorpay, automatically delivers download links or access instructions, and records customer order details.

## What You Can Do

- Choose product format: **Digital Download**, **Course / Content**, **Service / Consultation**, or **Physical Product**.
- Set base price, original comparison price (strikethrough discount), and currency.
- Upload product cover images and multi-image media galleries.
- Upload digital delivery files (PDFs, ZIPs, ebooks, design presets, video links).
- Write rich descriptions with markdown formatting and bullet points.
- Set inventory counts or enable unlimited stock.
- Configure automated order confirmation messages and download instructions.

## How to Use

### Step 1: Set Basic Information
1. Open **Products > All Products** and click **+ Add Product**.
2. Enter the **Product Name** (e.g., *"Ultimate Creator Guide 2026"*).
3. Select the **Category / Product Type**.
4. Write a detailed **Description** highlighting what buyers receive.

### Step 2: Set Pricing & Inventory
1. Enter the **Selling Price** (e.g., `₹499`).
2. Optional: Enter an **Original Price** (e.g., `₹999`) to show a discount badge.
3. For digital goods, select **Unlimited Inventory**. For physical items, enter available stock units.

### Step 3: Upload Product Media & Delivery Files
1. Click **Upload Product Images** to add showcase photos.
2. Under **Fulfillment / Download File**, upload the PDF, ZIP archive, or asset file delivered upon successful payment.
3. If selling a consultation service or course, provide the meeting/course access link and instructions.

### Step 4: Save & Publish
1. Review the generated product summary card.
2. Click **Publish Product**. Your product is now live on your bio page and ready for automated DM sales.

## Available Product Configuration Fields

| Field | Purpose |
|---|---|
| **Product Title** | Customer-facing name of the item. |
| **Product Type** | `Digital`, `Course`, `Service`, or `Physical`. Determines delivery workflow. |
| **Price (₹)** | The checkout purchase price charged to the buyer. |
| **Original Price (₹)** | Optional higher strikethrough price for promotional discounts. |
| **Product Description** | Full sales copy and features list. |
| **Media Images** | High-resolution thumbnail and gallery images. |
| **Digital Download File** | Asset securely hosted and delivered to buyers after verified payment. |
| **Access URL / Instructions** | Meeting link or external access instructions for services and courses. |
| **Inventory Count** | Stock units available for sale. |
